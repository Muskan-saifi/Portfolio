# Muskan Saifi — Portfolio

This is the existing React + Vite portfolio with the original dark theme, animated sections, navigation, and card styling preserved. The content has been personalized for Muskan Saifi.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Open this `portfolio` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed in the terminal.

## Contact form setup (optional)

The contact form needs your own Web3Forms access key. Create a key at https://web3forms.com/, then create a `.env` file in this folder and add:

```env
VITE_WEB3FORMS_ACCESS_KEY=your_own_key_here
```

Do not publish your `.env` file or share your access key. Until a key is configured, the contact form will tell visitors to email directly.
